# CleanOps — Checklist de limpieza Airbnb

## Deploy rápido en Vercel

1. Subí esta carpeta a un repo de GitHub
2. Entrá a vercel.com → New Project → importá el repo
3. Vercel detecta Vite automáticamente → Deploy
4. Listo, tenés una URL pública

## Uso

- **Admin:** entrá con contraseña `admin1234` (cambiala desde Config)
- **Operario:** usá el link único generado desde el panel de Operarios

## Stack
- React + Vite
- Supabase (base de datos + storage de imágenes)
